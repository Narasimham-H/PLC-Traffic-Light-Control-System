# PLC Traffic Light Control System

A PLC-based traffic light control system implemented using ladder logic and timer-based control.

## About the Project

This project was developed as part of the **Intelligent Industrial Automation: AI, Sensors, Actuators & PLC Integration** skill-development course.

The system uses a PLC program to control traffic signal outputs according to predefined timing conditions. Ladder logic and timer comparison instructions are used to control the sequence of the traffic lights.

## Project Objectives

- Control traffic signals automatically using a PLC.
- Implement sequential control using ladder logic.
- Use timer-based conditions for signal timing.
- Gain practical experience with PLC programming.

## Technologies Used

- PLC
- Ladder Logic
- Timer and Comparison Instructions
- Industrial Automation

## Project Files

- `traffic.rsl` — PLC ladder logic program
- `traffic.pdf` — Ladder logic diagram

## Working

The PLC timer keeps track of the elapsed time. Based on the timer's accumulated value, different output conditions are activated to control the traffic signal sequence.

The ladder logic program contains the timer and comparison conditions used for controlling the outputs.
